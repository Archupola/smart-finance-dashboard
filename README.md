# Smart Finance Dashboard

A full-stack finance management web application that helps users track expenses, monitor budgets, visualize analytics, and upload CSV files for expense management.

---

# Features

- Add and manage expenses
- Monthly budget tracking
- Expense analytics with charts
- Dark mode support
- CSV upload support
- Responsive UI
- MongoDB database integration

---

# Tech Stack

## Frontend
- React.js
- Vite
- Axios
- Recharts
- CSS

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

# Installation

## Clone Repository

```bash
git clone https://github.com/Archupola/smart-finance-dashboard.git
cd smart-finance-dashboard
```

# Frontend Setup

```bash
cd client
npm install
npm run dev
```

# Backend Setup

```bash
cd server
npm install
npm start
```

---

# Environment Variables

Create a `.env` file inside the server folder:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
